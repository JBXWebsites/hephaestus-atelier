# Project design context

HEPHAESTUS is a cinematic Greek mythology atelier and interactive portfolio experience for JBX Web Studio. Stack: Next.js, React, GSAP, Three.js. Primary context: PRODUCT.md, DESIGN.md, docs/21ST-COMPONENT-RESEARCH.md and docs/21ST-THEME-RESEARCH.md. Machine-readable decisions and constraints: design.json.

The charcoal workshop, warm limestone reading surface, and ember action accent come from one physical scene. Marcellus supplies inscription character; Manrope supplies readable controls. Both are self-hosted. Existing fictional artwork remains disclosed; no generated asset was added in this revision.

The visitor moves from maker to object studies to a working forge. One offset bronze crop gives the maker scene depth. A large exhibit stage and thumbnail index coordinate selection. The short invitation shares a dark ground with the gallery and forge. Mobile keeps the live object visible while selecting material and mark. Native buttons, anchors, fieldsets, and ordinary document flow remain the foundation.

All authored motion uses GSAP. Reduced motion presents the complete static composition. Do not import a second animation or smooth-scroll library, autoplay the gallery, or add unrelated gradients, pill CTAs, glass cards, and floating decorations.

The 21st references informed behaviors and composition; no catalog source was copied or installed. The custom OrbitLink and tactile forge action reuse this project's tokens and theme. Backend creation, record, download, sharing, and local collection are required behavior, not mock interactions.
